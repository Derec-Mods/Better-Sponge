## About

This plugin / server mod improves sponges while using the exact same Breadth-First Search algorithm vanilla uses, to try to mimic vanilla behavior the best it can while letting sponge have a way bigger radius.

Waterlogged blocks, coral plants, kelp, and seagrass will all be broken too! Waterlogged blocks will simply have their water drained. 

Plan to make it fully configurable too!
